# Keitaro Wrapper

Обёртка над Admin API рекламного трекера [Keitaro](https://keitaro.io):

1. **Создаватор кампаний** — по названию, гео и офферу создаёт кампанию с двумя потоками: трафик из выбранной страны уходит на Google, остальной — на оффер.
2. **Редактор кампании** — добавление и удаление офферов в потоке с пересчётом долей и статистикой.

Стек: FastAPI, SQLAlchemy 2 (async), Alembic, PostgreSQL; фронтенд — React, TypeScript, Vite, Mantine.

> Проект в разработке. Инструкции по миграциям и запуску появятся здесь по мере готовности.
